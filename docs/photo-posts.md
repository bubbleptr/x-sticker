# 文字封面与原始配图

v0.3 输出一组有序图片：文字卡贴在前，原帖配图在后。配图保留原始字节、尺寸与比例，不裁剪、不加背景；纯图片帖直接使用配图，第一张选中的图排在最前。

## 操作

1. 在 X 帖子的分享菜单点击「做成卡贴」，或使用工具栏入口。
2. 点击预览下方缩略图查看每张图片。勾选控制图片是否下载、同步，翻看图片不改变选择。文字封面固定保留，配图默认全选，选择仅作用于当前帖子。
3. 文字较短时，第一张配图会直接放进文字封面（和 X 详情页一样排在正文下方），不再单独输出。判断标准：合并后的卡片上下留白不小于左右留白，否则封面保持纯文字、第一张图单独一页。取消勾选这张图，封面会恢复纯文字。切换比例、改名等设置后会重新判断。
4. 右侧样式设置只作用于文字封面。纯图片帖隐藏这些设置，标题默认「图片分享」，可自行修改。
5. 只选择一张时直接下载原格式文件；多张时下载一个 ZIP。包内使用 `01-cover.png`、`02-photo.jpg` 等编号，取消配图后重新连续编号。
6. 同步草稿时，下载与同步使用相同顺序和内容。创建任务后继续编辑不会改变已发送的图片与文案。

选中的任意图片加载失败时，下载与同步会禁用。点击失败缩略图查看原因并重试，或取消该图；不会悄悄漏掉图片。纯图片帖必须至少选择一张。

## 素材范围

- 提取本帖的静态配图，排除头像、emoji、引用帖图片、链接预览和视频封面。
- 支持 PNG、JPEG、WebP。媒体从 `pbs.twimg.com/media/` 读取原尺寸版本，不发送 Cookie、不接受重定向。
- 单张最多 20 MiB，整组最多 40 MiB、20 张。这是扩展的传输限制，不保证所有平台都接受这些数量与尺寸。
- 不合并线程，不截取视频或 GIF。超长配图保留完整；在预览中按窗口缩小显示，下载不重采样。

## 草稿核对

所有图片一次按顺序交给文件上传控件。只有真实源图、上传后、保存前以及保存重开后的每张图片像素与顺序一致，才会显示「草稿已核对」。图片本身相同但顺序改变也会暂停。

平台若只展示压缩后的缩略图、图片超过 2400 万像素，或禁止读取像素，扩展无法确认原图，会要求人工核对。不会把相同张数当作内容一致。

升级前的单图任务保留原素材和执行检查点。关闭标签页、重启、停止或核对中断后，不重复上传，也不自动覆盖旧稿。最终发布仍由用户完成。

## 验证边界

回归覆盖抓取归属与顺序、原图读取失败、勾选与重试、纯图帖、异步预览、ZIP 独立解压、有序上传和保存核对。使用本地 Vite 与真实 Chrome 检查桌面、窄屏及长图完整显示；样本和截图位于忽略提交的 `artifacts/playwright/`。

这些浏览器页面模拟 Chrome 消息和平台编辑器，不代表真实平台验收。v0.3 多图同步仍需重新加载扩展、刷新 X 与创作者中心后实测。
