# 插件图标

正式图标采用设计稿中间的宽版卷角贴纸，保留原始轮廓和透明背景。正面为珊瑚红 `#ff4549`，背面为深蓝 `#102d50`。

矢量源文件位于 `public/icons/logo.svg`。修改源文件后执行：

```bash
npm run icons
npm run build
```

`icons` 命令生成 16、32、48、128px 的透明 PNG。Manifest 使用这些 PNG 作为工具栏和扩展管理页的图标。构建完成后，在 Chrome 扩展管理页重新加载插件即可查看更新。

页内预览顶栏在「X Sticker」文字前复用同一 SVG，桌面显示为 28px，窄窗口为 24px。它是装饰图形，不参与键盘焦点，也不重复朗读标题。
